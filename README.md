# LeetCode 문제 풀이 저장소

이 저장소는 LeetCode 알고리즘 문제 풀이를 주제별로 정리한 공간입니다.

## 폴더 구조

- `array/` : 배열 관련 문제
- `string/` : 문자열 관련 문제
- `linked_list/` : 연결 리스트 문제
- `backtracking/` : 백트래킹 문제
- `math/` : 수학/숫자 문제
- `stack/` : 스택 관련 문제
- `dynamic-programming/` : 동적 프로그래밍(현재 비어 있음)
- `binary-tree/`, `graph/` : 트리/그래프(현재 비어 있음)

각 폴더에는 문제 번호와 이름이 포함된 C++ 풀이 파일이 들어 있습니다.

## 사용법

1. 원하는 폴더에서 문제를 선택해 풀이를 확인하세요.
2. 파일명은 `문제번호_문제이름.cpp` 형식입니다.
3. 새로운 문제를 풀면 해당 주제 폴더에 파일을 추가하세요.
